# Student Information System (Java)

## Overview

This project is a console-based **Student Information System** developed in Java. It allows users to manage student records efficiently using basic CRUD (Create, Read, Update, Delete) operations along with data export functionality.

## Features

* Add new student details
* View all student records in tabular format
* Update existing student information
* Delete student records
* Export student data to a CSV (Excel-compatible) file

## Technologies Used

* Java (Core Java)
* ArrayList (for data storage)
* File Handling (FileWriter for CSV export)
* Scanner (for user input)

## Student Details Stored

* ID (Auto-generated)
* Moddle ID
* Name
* Roll Number
* Course
* Semester

## How to Run

1. Compile the program:

   ```
   javac StudentInformationSystem.java
   ```
2. Run the program:

   ```
   java StudentInformationSystem
   ```

## Output Options

* Console-based menu system
* CSV file export (`StudentData.csv`) which can be opened in Excel

## Conclusion

This project demonstrates the use of Java for building a simple data management system with file handling capabilities. It helps in understanding object-oriented programming, user interaction, and basic data storage techniques.
